# CrewSignal — MAVERICKS_CODE_E_MANIPAL

This repository contains the CrewSignal prototype for Code-E-Manipal 2.0. This commit creates an initial scaffold with a minimal frontend and backend so the project can build and run locally.

Quickstart (frontend):

1. cd frontend
2. npm install
3. npm run dev

Quickstart (backend):

1. python -m venv .venv
2. source .venv/bin/activate
3. pip install -r backend/requirements.txt
4. uvicorn backend.app.main:app --reload
